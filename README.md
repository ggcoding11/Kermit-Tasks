## 💻 Funcionalidades

* To-Do List (CRUD para as tarefas diárias)
* Timer de Pomodoro (25 min/ 5 min/ 30 min)
* Navegação entre os componentes (React)
* Botões estilizados em 3D
* Design responsivo (Bootstrap)
* Após a finalização de todas as tarefas, confetes aparecem na tela (JS Confetti)
* Notificações após pausa e retomada do timer (Notifications API)
